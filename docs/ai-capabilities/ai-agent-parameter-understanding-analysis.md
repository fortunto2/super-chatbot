# AI Agent Parameter Understanding Analysis

## Executive Summary

После анализа кода в `/lib/ai`, AI агент **ПОЛНОСТЬЮ ПОНИМАЕТ** параметры генерации изображений и имеет сложную систему их обработки.

## ✅ Что агент понимает отлично

### 1. Автоматическое улучшение промптов
- **Правила из `lib/ai/prompts.ts`**:
  ```
  - Русский текст → автоматический перевод
  - Короткие промпты (<50 символов или 5 слов) → улучшение
  - Простые описания → добавление качественных терминов
  ```

- **Процесс**: Агент проверяет промпт и вызывает `enhancePrompt` ПЕРЕД генерацией

### 2. Динамическая загрузка моделей
- Модели загружаются из SuperDuperAI API через `getImageGenerationConfig()`
- Кеширование на 1 час для производительности
- Fallback на старый кеш при ошибках API

### 3. Интеллектуальный подбор параметров

#### Стили
- Функция `findStyle()` поддерживает:
  - Точное совпадение по label или id
  - Частичное совпадение
  - Case-insensitive поиск
  
#### Разрешения
- Поддержка разных форматов:
  - "1920x1080", "1920×1080", "1920 x 1080"
  - "full hd", "fhd", "1080p"
  - "square", "vertical", "horizontal"

#### Shot Sizes
- Камерные углы: "close-up", "medium-shot", "long-shot"
- Поддержка как по id, так и по label

### 4. Умный выбор моделей
```javascript
// Из lib/ai/api/config-cache.ts
getBestVideoModel({
  requireTextToVideo: true // Приоритет text-to-video моделям
})
```

Приоритизация:
1. Sora для text-to-video
2. text_to_video > image_to_video
3. Сортировка по цене внутри типа

## ⚠️ Обнаруженные ограничения

### 1. Стили не обрабатывают русский ввод
```javascript
// findStyle не переводит русские названия
"аниме" → null (не найдено)
"anime" → flux_anime (найдено)
```

### 2. Сложная конвертация типов
- Множественные форматы моделей (VideoModel, AdaptedModel, GenerationConfig)
- Требуется унификация типов

### 3. Зависимость от API
- Если API недоступен, используется кеш
- Но первый запуск требует доступного API

## 🎯 Практические примеры работы агента

### Пример 1: Русский промпт
```
Пользователь: "нарисуй мальчика с мячиком"

Агент:
1. Определяет: русский текст + короткий (<50 символов)
2. Вызывает enhancePrompt(mediaType='image')
3. Получает: "boy playing with ball, professional photography..."
4. Вызывает configureImageGeneration с улучшенным промптом
```

### Пример 2: Выбор модели
```
Пользователь: "создай изображение с моделью FLUX"

Агент:
1. Загружает модели через getAvailableImageModels()
2. Ищет модель с name или label содержащим "FLUX"
3. Находит: comfyui/flux
4. Использует найденную модель
```

### Пример 3: Гибкое разрешение
```
Пользователь: "сделай картинку full hd"

Агент:
1. Парсит "full hd" 
2. Находит соответствие: 1920x1080
3. Применяет разрешение
```

## 📊 Статистика понимания

| Параметр | Уровень понимания | Детали |
|----------|-------------------|---------|
| Промпты | ⭐⭐⭐⭐⭐ | Автоулучшение, перевод |
| Модели | ⭐⭐⭐⭐⭐ | Динамическая загрузка |
| Стили | ⭐⭐⭐⭐ | Частичное совпадение, но без перевода |
| Разрешения | ⭐⭐⭐⭐⭐ | Множество форматов |
| Shot Sizes | ⭐⭐⭐⭐⭐ | ID и label |
| Seed | ⭐⭐⭐⭐⭐ | Опциональный параметр |
| Batch Size | ⭐⭐⭐⭐⭐ | 1-3 изображения |

## Заключение

AI агент имеет **продвинутое понимание** всех параметров генерации изображений:

1. **Автоматическая оптимизация** - улучшает простые промпты
2. **Гибкий парсинг** - понимает разные форматы ввода
3. **Умные дефолты** - выбирает оптимальные настройки
4. **Динамическая адаптация** - подстраивается под доступные модели

Агент готов к продакшн использованию и корректно обрабатывает большинство пользовательских запросов.
